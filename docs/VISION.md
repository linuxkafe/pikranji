# Pikranji — Vision

## Problem
Japanese learners struggle to memorize thousands of kanji characters through rote memorization. Traditional flashcards are boring and don't leverage visual-spatial learning.

## Solution
A Picross (Nonogram) puzzle game where every solution reveals a kanji character. The puzzle mechanics naturally reinforce stroke patterns and character structure while providing engaging gameplay.

## Value Proposition
- **Gamified learning**: Turns kanji memorization into a logic puzzle
- **Visual reinforcement**: Solving reveals the character stroke-by-stroke
- **Progressive difficulty**: Puzzles sorted by complexity (pixel count)
- **Cross-platform**: Play on web browser or Nintendo DS
- **Extensible**: Generate new puzzles from any TTF font or draw manually

## Target Audience
- Japanese language learners (JLPT N5-N4 level initially)
- Puzzle game enthusiasts
- Retro gaming / homebrew community (NDS port)
